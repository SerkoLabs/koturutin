# Store Readiness

Activate `research-first`; store rules are version-sensitive.

Check only applicable areas:
- account deletion/account lifecycle,
- privacy/data disclosures,
- permissions,
- tracking,
- UGC moderation/report/block,
- subscriptions/digital purchases,
- sign-in requirements,
- background capabilities,
- metadata/screenshots,
- release build/signing,
- crash/analytics configuration.

Verify behavior against the actual build. Do not rely on policy memory.
