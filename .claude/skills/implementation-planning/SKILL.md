# Implementation Planning

Input: all approved planning documents.
Output: `docs/IMPLEMENTATION_PLAN.md`.

Use `templates/IMPLEMENTATION_PLAN.template.md`.

Every task must have ID, purpose, work, likely affected modules, dependencies, acceptance criteria, verification and complexity.

Define the first end-to-end vertical slice explicitly. Prefer tasks small enough for one focused coding run.

Do not write application code during planning.
