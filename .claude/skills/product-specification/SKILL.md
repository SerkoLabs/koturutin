# Product Specification

Input: `README.md`.
Output: `docs/PRODUCT_SPEC.md`.

Use `templates/PRODUCT_SPEC.template.md`.

For every MVP feature define user goal, trigger, preconditions, happy/alternate paths, validation, permissions, loading/empty/error/offline behavior, analytics where useful, acceptance criteria, and explicit non-goals.

Do not add features merely to make the product seem complete. Resolve ambiguity toward the smallest MVP consistent with README.
