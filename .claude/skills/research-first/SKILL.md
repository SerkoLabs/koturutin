# Research First

Use this skill only when freshness matters.

Priority:
1. official documentation/policy,
2. standards bodies,
3. first-party repositories/changelogs,
4. reputable secondary sources.

For every material conclusion:
- record what was verified,
- record the date or version when relevant,
- link the source in the relevant project doc,
- distinguish facts from recommendations.

Do not let research expand MVP scope.
